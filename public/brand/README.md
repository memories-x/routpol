# Marka varlıkları

| Dosya | Kullanım |
|-------|----------|
| `mark.svg` | Header / footer logo (32–40px yükseklik) |
| `/favicon.svg` | Sekme ikonu (`app` metadata) |

Renkler: navy `#0F1C2E`, emerald `#059669`, bg `#F8FAFC` (`pt-*` tokenler).

Panel sonuç PDF’i: `src/lib/pdf/stamp-branded.ts` aynı bantları sunucuda basar
(pdf-cevirmen `stamp_word_pdf` ile aynı ölçü). Bant metni Helvetica (portable ASCII).

İleride: tasarım ajansı wordmark PNG/SVG ile `mark.svg` değiştirilebilir; path aynı kalsın.
