# Public visual brief (operator → agent)

Copy into chat before a visual tur. Incomplete brief → agent asks; does not invent direction.

```yaml
surface: # ONE of: hero | header | scope | bridge | packages | process | faq | lead | footer | hub-packages | tokens
keep: # what must not change
change: # what feels wrong today (1–3 bullets)
references: # 2–3 URLs, or "reuse: quiet-authority"
success: # how you will accept (e.g. "hero less SaaS, brand still first")
browser_routes: # default [/tr] — add /tr/hizmetler if hub
restore: quiet authority baseline'a dön
```

## Agent checklist (do not skip)

- [ ] Brief complete
- [ ] Snapshot/restore known
- [ ] Plan lists one surface
- [ ] Implement
- [ ] Browser screenshots (desktop + mobile if possible)
- [ ] Fixes from what was seen
- [ ] `node scripts/pre-commit-guard.js`
- [ ] Report + restore phrase
